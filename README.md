# ipa-exam-corpus

独立行政法人情報処理推進機構（IPA）が公表している、基本情報技術者試験（FE）と応用情報技術者試験（AP）の午前問題（FE は 2023 年度以降「科目A」）の問題冊子 PDF をまとめたコーパスです。

> **本リポジトリは非公式のものであり、IPA とは一切関係ありません。** IPA が作成・承認・監修したものではありません。最新・正確な情報は [IPA 過去問題ページ](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html) を参照してください。

## 収録内容

| 試験区分 | 範囲 | ファイル数 |
|---|---|---|
| 基本情報技術者試験（FE）午前 | 平成21年度 春期 〜 令和元年度 秋期 | 22 |
| 基本情報技術者試験（FE）公開問題 科目A | 令和5年度 〜 令和8年度 | 4 |
| 基本情報技術者試験（FE）科目A サンプル問題セット | — | 1 |
| 応用情報技術者試験（AP）午前 | 平成21年度 春期 〜 令和7年度 秋期 | 33 |

- 問題冊子のみを収録しています（解答例・採点講評は含みません）。
- FE の令和2〜4年度は CBT 方式への移行に伴い問題冊子が公開されていないため、収録していません。

```
IPA_FE_AP_午前問題_PDF/
├── 取得一覧.csv          # 各ファイルの取得元URL・サイズ・SHA256
├── FE/<年>/*.pdf
└── AP/<年>/*.pdf
```

## 著作権・出典

収録している PDF の著作権は **IPA** に帰属します（IPA は著作権を放棄していません）。本リポジトリでは、IPA が公表している次の利用条件に基づき、IPA の配布ファイルを **無改変のまま** 再配布しています（[IPA「試験に関するよくある質問」](https://www.ipa.go.jp/shiken/faq.html)）。

- 公表済みの過去問題の使用には、法令に特別の定めがある場合を除き、許諾や使用料は不要
- 出典（年度・期・試験区分・時間区分・問番号など）を明記すること
- 問題を一部改変した場合はその旨を明記すること

各 PDF の出典は [ATTRIBUTION.md](ATTRIBUTION.md) に一覧で記載しています。

### このコーパスを利用する方へ

問題を引用・転載・加工して利用する場合は、IPA の条件に従い、**問番号まで含めた出典** を明記してください。

```
出典：令和7年度 春期 応用情報技術者試験 午前 問1
出典：令和7年度 春期 応用情報技術者試験 午前 問1（一部改変）   ← 改変した場合
```

また、IPA が作成したものと誤認させる形での利用や、試験制度の意義に反する利用は避けてください。問題文中の会社名・製品名は、一般に各社の商標または登録商標です。

## 改変していないことの確認

`取得一覧.csv` に各ファイルの取得元 URL と SHA256 を記録しています。以下で IPA 配布物と同一であることを確認できます。

```sh
cd IPA_FE_AP_午前問題_PDF
python - <<'EOF'
import csv, hashlib, os
for r in csv.DictReader(open('取得一覧.csv', encoding='utf-8-sig')):
    p = os.path.join(r['Exam'], r['Year'], r['File'])
    ok = hashlib.sha256(open(p, 'rb').read()).hexdigest().upper() == r['SHA256']
    print('OK ' if ok else 'NG ', p)
EOF
```
